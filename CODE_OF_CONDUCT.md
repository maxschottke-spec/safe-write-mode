# Code of Conduct

We use the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as our code of conduct.

## In short

- Be kind. Critique the code, not the person.
- Assume good intent. Ask questions before accusing.
- No harassment, no discrimination, no name-calling.
- Maintainers will moderate. Decisions are final.

## Reporting

Report violations privately to the maintainer through the repository's **Security** tab (**Report a vulnerability** is a private channel) or, for anything that can be public, in an issue. All reports are reviewed.

## Scope

This applies to all project spaces (issues, PRs, discussions, related chats) and to community members representing the project in public.
